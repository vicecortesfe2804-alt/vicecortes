Privacy Policy — Vice Cortes Studio

Last updated: November 21, 2026

1. Who uses the tool

Vice Cortes Studio is an internal tool used only by the owner of the Vice Cortes channel, with the channel's own TikTok account. It has no public users.

2. Data we access

  • user.info.basic: the account's display name, avatar and open ID, used only to confirm that the connected account is the Vice Cortes account.
  • video.upload: permission to send video drafts to that account's TikTok inbox.

3. How data is stored

The access token is stored only on the channel owner's own computer, in a local configuration file. No data is sold, shared with third parties, or used for advertising. No data about TikTok viewers or other users is collected.

4. Deleting data

The owner can revoke access at any time in the TikTok app (Settings → Security → Apps and services) and delete the local file. Removing the tool deletes all stored data.

5. Contact

Questions can be sent through the channel's profiles: TikTok @vicecortes.vl or YouTube.
